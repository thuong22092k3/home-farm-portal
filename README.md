# Home Farm Portal

Ứng dụng quản lý dành riêng cho Farmer của Vườn Nhà.

## Chạy local

```bash
npm install
npm run dev
```

Mở `http://localhost:3000/dashboard`. Ứng dụng chỉ sử dụng tiếng Việt.

## Routes

- `/dashboard` — Tổng quan
- `/trees` — Sơ đồ cây
- `/rentals` — Đơn thuê
- `/journal` — Nhật ký vườn
- `/reports` — Báo cáo
