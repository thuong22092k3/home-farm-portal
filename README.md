# Home Farm Portal

Ứng dụng quản lý dành riêng cho Farmer của Vườn Nhà.

## Chạy local

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`. Ứng dụng hỗ trợ tiếng Việt tại `/vi/dashboard` và tiếng Anh tại `/en/dashboard`.

## Routes

- `/[lang]/dashboard` — Tổng quan
- `/[lang]/trees` — Sơ đồ cây
- `/[lang]/rentals` — Đơn thuê
- `/[lang]/journal` — Nhật ký vườn
- `/[lang]/reports` — Báo cáo
